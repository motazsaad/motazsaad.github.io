# Arabic — The Language of a Thousand Voices

A static, single-page website celebrating the Arabic language: its history, alphabet, grammar, dialects, and global influence.

## Features

- **Interactive alphabet** — click any of the 28 letters to see its isolated/initial/medial/final forms and pronunciation notes
- **Multilingual** — English, العربية (RTL), Français, Español, and Italiano via the nav selector; the chosen language is remembered in `localStorage`
- **Sections** — history timeline, root-based grammar cards, dialect samples, Arabic loanwords, and learning resources
- **Responsive** — mobile nav, fluid grids, scroll-reveal animations, and reduced-motion support

## Tech

- Plain HTML, CSS, and vanilla JavaScript — no build step or dependencies
- Google Fonts: [Amiri](https://fonts.google.com/specimen/Amiri) (Arabic) and [Inter](https://fonts.google.com/specimen/Inter)

## Run locally

Open `index.html` in any browser — no server needed.

```
git clone https://github.com/motazsaad/motazsaad.github.io.git
```

## Structure

```
index.html        Page markup
css/style.css     Styling (LTR/RTL, responsive)
js/main.js        Alphabet data, translations, nav, animations
```
